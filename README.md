# TONPUKU+

頓服薬の服用記録・効果評価アプリ。

- 服用記録、経過観察、効果・副作用の評価
- 服用履歴の一覧
- 医療者向けサマリー（診察時に共有できるレポート）
- 頓服薬の登録・管理

## データについて

すべてのデータはブラウザの `localStorage` に保存されます。サーバーへの送信は一切行いません。

## ローカルで開く

```bash
python3 -m http.server 8000
```

`http://localhost:8000` を開く。

## デプロイ

静的な `index.html` 一枚のみで動作するため、Vercel / Netlify / GitHub Pages などにそのままデプロイできます。
